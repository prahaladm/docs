## Overview

**CONFIG → Skills** is a pane for authoring custom instruction files, presumably meant for the AI Assistant to read while it works on your project — the same idea as a project-level system-prompt fragment.

<Note>
**This pane is badged Alpha, and its one available action does not currently work.** Everything below is a straight report of what was observed, including a bug: creating a file here does not survive a reload. Read this page as a status report, not a how-to.
</Note>

Reached by expanding **CONFIG** in the left sidebar and clicking the book icon, whose tooltip reads **"Skills Alpha."**

## What it looks like, empty

A **Search skills…** box across the top, a **+** button (tooltip: **Add Custom Skill**) at the top right, an empty file list on the left, and a centred **"Select a file to view"** placeholder on the right.

This project has no skills at all, built in or custom. Searching for a single letter returned nothing, so there is no hidden default catalog being filtered out — the pane is genuinely empty until you create something.

## Clicking + creates a file immediately — no naming dialog

Clicking **+** does not ask for a name or description. It immediately adds a row to the file list, under a new **CUSTOM** group heading, named `new-skill`. That is the same pattern as **API Calls**' own **+ Add** button, covered in [Data & APIs](/guides/connect-an-api): the click *is* the create action.

Right after the click, the project's top-bar save indicator reads **"Saving…"** — ordinarily, everywhere else in Studio, the sign that a real save request went out.

## What survives a reload: nothing

Despite the "Saving…" indicator, reloading the page and reopening Skills shows the exact same empty state as before — no `new-skill` file, no **CUSTOM** group, nothing. This was reproduced three times, including once from a completely fresh browser session, and the result was identical every time.

<Warning>
**As of this pass, Skills cannot be used to create anything that lasts.** The create action is visually instant and the save indicator fires, but nothing is actually persisted to the backend. Whatever this pane is meant to hold once it works, it doesn't yet.
</Warning>

Not verified, and blocked by the bug above: what a skill file's editor looks like once genuinely open on a persisted file; whether the AI Assistant actually reads anything from this pane; whether "Custom" implies some other, non-custom category of skill that simply isn't populated in this project.

## Summary

Skills is a CONFIG pane for custom instruction files, currently Alpha and currently broken: clicking its only action creates a file that a "Saving…" indicator claims was saved, and a reload proves otherwise, every time. Nothing here should be relied on to persist until that's fixed.
